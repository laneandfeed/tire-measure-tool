# Changelog

## 2.0.0
- Redesigned instrument-style UI: menu bar, toolbar, tool rail, rulers, card-based side panel
- Added bead contour (polyline) tool
- Added labelme-style polygon tool with snap-to-first-point, label prompt, area and perimeter
- Labels can be moved, renamed, recoloured (colour wheel and presets) and reordered
- Esc cancels the current drawing, Backspace removes the last point
- Alt+Wheel and Shift+Wheel scroll sideways
- Window sizes itself from the usable screen area; F11 toggles full screen
- Lengths are stored in pixels, so recalibrating updates all measurements
- Optional sub-pixel snapping via `marker_snap.py`

## 1.0.0
- Calibration, two-point measurement, zoom/pan, magnifier loupe, unit switching, annotated export
